# Dataset attribution and license

This project includes `Data/Absenteeism_at_work.csv`, obtained from the UCI Machine Learning Repository **Absenteeism at work** dataset.

**Citation**

Martiniano, A. & Ferreira, R. (2012). *Absenteeism at work* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5X882

- Source: https://archive.ics.uci.edu/dataset/445/absenteeism
- DOI: https://doi.org/10.24432/C5X882
- License: **Creative Commons Attribution 4.0 International (CC BY 4.0)** — https://creativecommons.org/licenses/by/4.0/

The data is included to reproduce a learning and portfolio demonstration. The dashboard loads the semicolon-delimited source data and applies transformations for visualizations, summaries, modeling, and exports. Original files remain credited to the dataset creators.

**License distinction:** CC BY 4.0 is the license of the UCI dataset. No separate open-source software license has been selected for this dashboard code.
